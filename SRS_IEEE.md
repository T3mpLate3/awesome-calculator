# Спецификация Требований к Программному Обеспечению (SRS) для "Awesome Calculator"

(Составлено на основе ISO/IEC/IEEE 29148-2011)

## 1. Введение

### 1.1. Цели
Целью данного документа является определение функциональных и нефункциональных требований к программному изделию "Awesome Calculator".

### 1.2. Соглашения о терминах
*   **Числа Фибоначчи:** Последовательность, в которой каждое последующее число равно сумме двух предыдущих.
*   **Десятиугольные числа:** Фигурные числа, которые можно представить в виде Десятиугольника.
*   **CLI:** Command-Line Interface.

### 1.3. Предполагаемая аудитория
Документ предназначен для разработчиков, тестировщиков и заказчика проекта.

### 1.4. Масштаб проекта
Проект представляет собой простое консольное приложение для вычислений.

## 2. Общее описание

### 2.1. Видение продукта
"Awesome Calculator" — это утилита для командной строки, которая позволяет быстро вычислять числа Фибоначчи и Десятиугольные числа. Продукт должен быть простым, интуитивно понятным и надежным.

### 2.2. Функциональность продукта
Продукт предоставляет две основные функции: вычисление N-го числа Фибоначчи и вычисление N-го Десятиугольного числа.

### 2.3. Классы и характеристики пользователей
Целевой пользователь — любой человек, знакомый с основами работы в командной строке.

### 2.4. Среда функционирования продукта
Операционная система: Windows, macOS, Linux.
Среда исполнения: Python 3.6+.

### 2.5. Рамки, ограничения, правила и стандарты
*   Приложение не должно использовать внешние библиотеки, кроме стандартных библиотек Python.
*   Код должен соответствовать стандарту PEP 8.

### 2.6. Допущения и зависимости
*   Предполагается, что у пользователя установлен Python 3.
*   Работа приложения зависит от корректности ввода данных пользователем.

## 3. Функциональность системы

### 3.1. Функциональный блок 1: Вычисление чисел Фибоначчи

*   **Описание:** Пользователь может запросить вычисление N-го числа Фибоначчи.
*   **Функциональные требования:**
    *   **FR-1.1:** Система должна принимать в качестве аргумента командной строки команду `fib` и целое число `N`.
    *   **FR-1.2:** Система должна вычислять N-е число Фибоначчи, где F(0)=0, F(1)=1.
    *   **FR-1.3:** Система должна выводить результат в формате: "Число Фибоначчи для N=N: [результат]".

### 3.2. Функциональный блок 2: Вычисление Десятиугольных чисел

*   **Описание:** Пользователь может запросить вычисление N-го Десятиугольного числа.
*   **Функциональные требования:**
    *   **FR-2.1:** Система должна принимать в качестве аргумента командной строки команду `pent` и целое число `N`.
    *   **FR-2.2:** Система должна вычислять N-е Десятиугольное число по формуле P(n) = n(3n-1)/2, где P(0)=0.
    *   **FR-2.3:** Система должна выводить результат в формате: "Десятиугольное число для N=N: [результат]".

## 4. Требования к внешним интерфейсам

### 4.1. Интерфейсы пользователя (UX)
Интерфейс — командная строка. Взаимодействие происходит через вызов скрипта с аргументами.
Пример: `python main.py fib 10`

## 5. Нефункциональные требования

*   **NFR-1. Производительность:** Время вычисления для N до 1000 не должно превышать 1 секунды.
*   **NFR-2. Надежность:** Приложение должно корректно обрабатывать некорректный ввод, не завершаясь с ошибкой.
*   **NFR-3. Удобство использования:** Сообщения об ошибках должны быть понятными для пользователя.

## 6. Прочее

*   **N:** Целое неотрицательное число, вводимое пользователем.
