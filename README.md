# Awesome Calculator

## Описание задачи

Данный проект представляет собой консольное приложение на языке Python 3, предназначенное для выполнения математических вычислений. Основная задача — предоставить пользователю простой и удобный инструмент для расчета специфических числовых последовательностей: **чисел Фибоначчи** и **фигурных чисел**.

Приложение реализует модульную архитектуру и предоставляет командно-строчный интерфейс (CLI) для взаимодействия.

## План разработки

1.  **Этап 1: Проектирование и документация**
    *   Создание Git-репозитория.
    *   Написание `README.md` с планом разработки.
    *   Разработка Технического Задания (ТЗ) на основе ГОСТ 34.602-2020.
    *   Разработка Спецификации Требований к ПО (SRS) на основе ISO/IEEE 29148-2011.

2.  **Этап 2: Разработка ядра приложения**
    *   Создание модуля `math_utils.py` для реализации алгоритмов вычисления.
    *   Реализация функции вычисления N-го числа Фибоначчи.
    *   Реализация функции вычисления N-го фигурного числа (разновидность: пятиугольные числа).

3.  **Этап 3: Разработка интерфейса**
    *   Создание главного файла `main.py` с реализацией CLI.
    *   Интеграция модуля `math_utils.py` в основной файл.
    *   Обработка пользовательского ввода и вывод результатов.

4.  **Этап 4: Тестирование и отладка**
    *   Проверка корректности вычислений.
    *   Тестирование обработки ошибочных сценариев (неверный ввод).

5.  **Этап 5: Финализация**
    *   Создание файла-модуля `fibonacci_module.py` (в соответствии с заданием).
    *   Проверка соответствия требованиям ТЗ и SRS.
    *   Финальный коммит.
